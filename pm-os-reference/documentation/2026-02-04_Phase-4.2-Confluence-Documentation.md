## Search-Before-Create Pattern

**Objective**: Prevent duplicate pages by searching before creating

**Implementation** (via Rovo MCP natural language):
```
Before creating page:
1. "Search Confluence PMOS space for pages with title [page-name]"
2. If exact match exists → Update existing page OR create versioned copy
3. If no match → Create new page
```

**Example Workflow**:
```
User: "Create a Confluence page for the Phase 5 PRD"

Agent Steps:
1. Search: "Find Confluence pages in PMOS with title 'Phase 5'"
2. Result: "No exact match found"
3. Create: "Create page in PMOS: 'Phase 5 - Data Intelligence Layer PRD'"
4. Confirm: "Page created at [URL]"
```

## Technical Considerations

### Rovo MCP vs Custom Implementation
**Using**: Atlassian Rovo MCP (natural language interface)
**Not Using**: Custom Confluence REST API calls

**Natural Language Commands** (via Rovo MCP):
- `"Create a Confluence page in PMOS: [title]"`
- `"Update Confluence page [page-id] with content: [content]"`
- `"Search Confluence PMOS space for [query]"`
- `"Get Confluence page [page-id] content"`

**Note**: Rovo MCP handles OAuth, permissions, and API complexities automatically.

### Markdown → Confluence Conversion
**Challenge**: Confluence uses ADF (Atlassian Document Format), not Markdown

**Options**:
1. **Option A**: Let Rovo MCP handle conversion (test if supported)
2. **Option B**: Use Confluence's Markdown macro (embed markdown as-is)
3. **Option C**: Convert markdown to HTML, then to ADF (complex)

**Recommendation**: Test Option A first. If Rovo MCP accepts markdown natively, use that. Otherwise, use Confluence Markdown macro.

## Risks & Mitigations

### Risk 1: Bulk Page Creation Limitations
**Risk**: Rovo MCP may not support bulk page creation (25 pages at once)
**Mitigation**: Create pages sequentially with delay between requests (rate limiting)

### Risk 2: Markdown Formatting Loss
**Risk**: Complex markdown (tables, code blocks, mermaid diagrams) may not convert properly
**Mitigation**: Test with sample page first, use Confluence macros for complex content

### Risk 3: Page Hierarchy Complexity
**Risk**: Parent-child relationships may be hard to establish via natural language
**Mitigation**: Create parent pages first, note page IDs, reference when creating children
