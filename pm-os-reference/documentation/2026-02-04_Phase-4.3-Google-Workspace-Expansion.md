# Phase 4.3: Google Workspace Expansion (Docs, Slides, Sheets)

**Date**: 2026-02-04
**Status**: Planned (Not Started)

## Objective

Expand beyond Google Drive's read-only document retrieval to enable **creation and editing** of Google Docs, Slides, and Sheets. This transforms PM OS from a document reader into a document generator, enabling auto-generated executive summaries, phase retrospectives, and metrics dashboards.

---

## Strategic Context

### What Phase 1 Google Drive MCP Provided ✅
- **Read-only access** to existing Google Drive files
- OAuth 2.0 authentication flow (working, 514ms latency)
- Document retrieval for legacy context

### What Phase 4.3 Adds 🆕
- **Write access**: Create new Docs, Slides, Sheets
- **Edit access**: Update existing documents programmatically
- **Template-based generation**: PRD summaries, retrospectives, dashboards
- **Auto-export workflows**: Confluence → Slides, Jira data → Sheets

## Technical Considerations

### MCP Server vs Google Workspace MCP
**Question**: Is there an official Google Workspace MCP server?

**Research Required**:
1. Check https://github.com/modelcontextprotocol/servers for Google Workspace MCP
2. If exists: Use official server (similar to Atlassian Rovo MCP)
3. If not: Build custom MCP servers for Docs, Slides, Sheets

**Recommendation**: Research first. If official Google Workspace MCP exists, use it. Otherwise, build custom using Phase 1 Google Drive patterns.

### Markdown → Google Docs Conversion Complexity
**Challenge**: Google Docs uses complex JSON structure, not HTML or markdown

**Options**:
1. Use google-docs-converter library (npm)
2. Build custom markdown parser
3. Use intermediate HTML format

**Recommendation**: Test google-docs-converter first for speed.

### Template Management
**Challenge**: Templates need to be versioned and maintained

**Options**:
1. Store template IDs in `.env` (one-time manual creation)
2. Create templates programmatically (complex, but reproducible)
3. Store templates in shared Google Drive folder

**Recommendation**: Option 1 for Phase 4.3 (manual creation + ID storage). Option 2 for future enhancement.

---

## Risks & Mitigations

### Risk 1: OAuth Scope Expansion Requires New Consent
**Risk**: Adding new scopes may break existing Google Drive MCP
**Mitigation**: Test in separate OAuth app first, migrate when stable

### Risk 2: Google Docs JSON Complexity
**Risk**: Markdown conversion may be error-prone (lose formatting)
**Mitigation**: Start with simple formatting (headings, paragraphs, lists). Add complexity incrementally.

### Risk 3: Template Maintenance Burden
**Risk**: Templates need updates as PM OS evolves
**Mitigation**: Version templates (v1, v2), document template IDs in code comments

### Risk 4: Rate Limits (Google APIs)
**Risk**: Bulk document creation may hit rate limits
**Mitigation**: Implement exponential backoff, batch operations where possible
